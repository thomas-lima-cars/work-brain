# Marca — C6

Logos entregues pelo Thomas em 2026-09-24 (`Downloads/Logos C6`). **Uma arte
por tema**, sem versão curta: a marca já é o monograma "C6".

**O `viewBox` foi recortado.** Os originais vêm num canvas de 80 × 60 com o
desenho no meio; a 26px de altura a marca ficaria com ~11px de desenho. A
caixa do desenho foi **medida com `getBBox`** no navegador — 43,26 × 22,87
(1,89:1), igual nas duas, com o desenho do branco deslocado 0,2 para a
direita — e o `viewBox` recorta com meio ponto de folga. `width`/`height`
acompanham o recorte: sem isso a proporção intrínseca seria a do canvas.
