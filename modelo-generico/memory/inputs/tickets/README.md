# `tickets/` — snapshots do rastreador de tarefas

Jira, Linear, Trello, Asana — o que for. Snapshot do estado num momento, pra dar ao brain
uma visão que ele não consegue consultar ao vivo.
Padrão de nome: `<YYYY-MM-DD>-<board-ou-filtro>.md`

Se você não usa rastreador, esta pasta fica vazia — e a `/rotina` trabalha só com o brain.
