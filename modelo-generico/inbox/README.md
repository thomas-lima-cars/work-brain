# `inbox/` — captura rápida

Coisa que apareceu e ainda não tem lugar. Jogue aqui em vez de perder.

Um arquivo por captura: `<YYYY-MM-DD>-<assunto-curto>.md`. Ou uma linha num arquivo só,
se for miudeza — o formato importa menos que o hábito.

**Regra:** o `inbox/` é estação de passagem, não depósito. O que sobreviver a duas semanas
aqui ou vira frente, ou vira arquivo de domínio, ou é descartado conscientemente.
