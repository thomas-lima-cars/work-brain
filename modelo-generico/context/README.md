# `context/` — quem eu sou

Os únicos arquivos, além do `estado-atual.md`, que o `/cerebro` lê **em toda sessão**.
Por isso precisam ser pequenos e de alto valor: cada linha aqui é paga em todo boot.

| Arquivo | Pergunta que responde |
|---|---|
| `empresa.md` | Onde eu trabalho, o que a empresa faz, como ela ganha dinheiro |
| `meu-papel.md` | O que eu faço, do que respondo, o que não é meu |
| `produtos.md` | O que existe, pra quem serve, em que estado está |
| `stakeholders.md` | Quem são as pessoas recorrentes e como cada uma funciona |

Preenchidos na primeira sessão, via entrevista do `/cerebro`. Depois disso, mudam pouco —
revisite quando trocar de time, de papel ou quando entrar alguém novo no jogo.

**Não coloque aqui** o que muda toda semana. Isso é `estado-atual.md`.
